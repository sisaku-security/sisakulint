
# YAMLパーサ/アンパーサのゴール

Go言語のyamlパーサー/アンパーサ―を作成する

1. 完全可逆
2. 任意の粒度(トークン、木、文字列)での置換が簡単かつ可逆
 + コマンドパターンなどが有効かもしれない 
3. github actionsのworkflow yamlやactions.yamlの分析用途に十分耐える
4. メモリ消費が少ない
5. 速度が速い
6. 人間が保守メンテするのが容易
 + LLMだけが触れるような状態ではだめ
 + 過剰な言い訳コメントをつけない
7. 無駄なコピペが少ない
 + どの機能がどこにあるかを最初から探してわかるようにしておく。
 + 単一層に情報が増えすぎたら階層化
